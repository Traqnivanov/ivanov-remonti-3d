## Core idea

**Real object/model ↔ service ↔ exact place in the model ↔ quantity ↔ price ↔ short client Info ↔ final result.**

The product is not a generic CAD clone and not a construction animation. Its differentiator is the interactive **Smart Offer** mechanism: the client can select an offer position and see exactly where it applies, or select part of the model and see the linked offer positions.
