## Core idea

**Real room/photos + confirmed dimensions → editable 2D/3D model → renovation operations by stage → realistic visualization → quantities → unit prices → final client presentation.**

The product is not a generic CAD clone. Its differentiator is the direct link between **construction sequence, geometry, quantity, price and client-visible result**.
