# Ivanov Remonti Smart Offer

Interactive renovation offer and visualization system.

## Start here

Every new project/work chat starts with:

1. [START_HERE.md](START_HERE.md) — durable operating rules and dependency map
2. [PROJECT_STATE.md](PROJECT_STATE.md) — single official current state
3. the **Current Work Issue** linked from `PROJECT_STATE.md`
4. verify the actual branch / HEAD / PR
5. read only the dependency contracts required for the current task

Do not reconstruct current state from old handoff files or chat memory.

## Core idea

**Real object/model ↔ service ↔ exact place in the model ↔ quantity ↔ price ↔ short client Info ↔ final result.**

The product is not a generic CAD clone and not a construction animation. Its differentiator is the interactive **Smart Offer** mechanism: the client can select an offer position and see exactly where it applies, or select part of the model and see the linked offer positions.
